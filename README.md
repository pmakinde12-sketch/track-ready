# Track Ready

Rule Book revision for UK track workers: quick questions plus 3D site scenarios.

- `index.html` – front page
- `app.html` – revision app (questions, mock tests, what's changed, handbooks)
- `scenario1.html` – PTS: open line, lookout warning
- `scenario2.html` – COSS: set up the safe system
- `scenario3.html` – AC lines: ladder under the wires
- `employer.html` – employer dashboard (demo data)
- `track-ready-promo.mp4` – 42s promo video

Practice tool only. Not official training or assessment. Questions are written in original wording and reference the current Rule Book handbooks (published by RSSB). Not affiliated with Network Rail or RSSB.

Uses three.js (MIT licence), loaded from cdnjs.
