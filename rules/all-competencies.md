# Track Ready rule maps (all competencies except PTS)

Each rule below is covered by one micro-scene in `micro.html?c=<comp>`. Wording is our own, written from the current handbooks.


## COSS · Handbook 7 (Issue 10) (48 rules)

| Scene | Rule |
|---|---|
| `coss-arm` | COSS armlet: white letters on blue, left arm (or a chest badge) |
| `coss-armoff` | Only wear the COSS armlet while acting as COSS |
| `coss-walkoff` | If you can reach site without going on or near the line, you must |
| `coss-2m` | No blocking, no barrier: nobody within 2 m of the nearest rail of an open line |
| `coss-rigid` | Rigid, tensioned barrier or permanent fence at 1.25 m: work on the safe side |
| `coss-tape40` | Tape or netting at 1.25 m only where line speed is 40 mph or less |
| `coss-tape2m` | Tape or netting at 2 m or more: no speed restriction |
| `coss-09` | A barrier at 0.9 m with ATWS must not be part of your safe system |
| `coss-affect` | Work that affects line safety needs the line blocked first |
| `coss-ladder` | Ladders must be secured so they can't fall towards the line |
| `coss-blocked` | Only treat a line as blocked under HB8, a PC, an ES work site/protection zone or a PICOS siding |
| `coss-walk3m` | Walking: keep everyone at least 3 m from any open line, or set up a safe system |
| `coss-walksw` | Site wardens or lookouts can't be the safe system for a walking group |
| `coss-brief` | Brief the group and get the RT9909 signed before walking or working |
| `coss-briefwhat` | The briefing covers the work, lines open/blocked, barriers, warnings, positions of safety, lookouts/wardens |
| `coss-join` | Anyone joining speaks to you first; set up the safe system before they join |
| `coss-leave` | Stay with the group, or stop work and get everyone to safety (or hand over to another COSS) |
| `coss-contact` | Everyone in sight and in verbal contact, without phones or radios |
| `coss-cantsee` | Can't observe the group properly: stop work, everyone to safety |
| `coss-cond` | If protection fails or conditions change, stop work and get everyone to safety |
| `coss-split` | Nobody works separately unless a COSS sets up a safe system for them |
| `coss-order` | Safe systems in order: safeguarded, fenced, separated, equipment warning, lookout warning |
| `coss-safeg` | Safeguarded = every line at the site is blocked |
| `coss-separ` | Separated = at least 2 m from the open line with a site warden |
| `coss-two` | With only you and one other: no site warden needed, but neither within 2 m |
| `coss-test` | Set up the system, test it and brief everyone before work starts |
| `coss-limit` | Every safe system needs an identifiable limit to the site of work |
| `coss-swpos` | Site wardens: competent, armlet, positioned to see limits and group; test the warning |
| `coss-swyou` | A COSS acting as site warden takes no part in the work |
| `coss-noise` | Work noise must not stop anyone hearing the equipment warning |
| `coss-10s` | Equipment warning: everyone stops and reaches safety at least 10 s before a train |
| `coss-shared` | Agree with the other user how the equipment will be operated, and whether it stays on |
| `coss-lo25` | Lookout warning only where approaching trains are 25 mph or less |
| `coss-lodir` | Lookouts only if no alternative, planned in advance, director-level authorisation |
| `coss-lo25m` | With lookouts, nobody walks more than 25 m to the position of safety |
| `coss-lo45` | Required warning time with lookouts must be 45 s or less |
| `coss-calc` | Warning time = stop work + walk to safety + 5 s per extra direction + 10 s in safety |
| `coss-routed` | No lookouts if a train could be routed onto the line after the lookout has seen it |
| `coss-meLO` | The COSS must not act as lookout; nobody crosses an open line to reach safety |
| `coss-lodark` | No lookouts in darkness, poor visibility, or in or near a tunnel |
| `coss-bidir` | On single, bi-directional or SLW lines, warn for both directions |
| `coss-lopos` | Each lookout knows lines and directions, isn't distracted, does no work; test the warning |
| `coss-tools` | Take tools to safety unless too heavy to be moved by slipstream; then leave them clear of the line |
| `coss-ctl4` | Crossing the Line: up to four lines, approved location, competent, nobody working |
| `coss-ctlcall` | Phone the signaller: crossing location, name and employer, time needed; stay on until all across |
| `coss-dets` | Place detonators only after the PICOP confirms the protecting signal is at danger |
| `coss-wsmb` | Place work-site marker boards only with the ES's permission |
| `coss-visitor` | Visitors with a permit: brief them, sign and keep the permit, stay with them |

## IWA · Handbook 6 (Issue 8) (18 rules)

| Scene | Rule |
|---|---|
| `iwa-cert` | Carry a valid IWA certificate |
| `iwa-walkoff` | If you can reach site without going on or near the line, do |
| `iwa-when` | When an IWA may walk on or near the line |
| `iwa-obst` | Obstacle onto an open line: alternative route, then company alternative, then block the line |
| `iwa-cross` | Cross only where the safe work pack defines it, by Crossing the Line, or at a planned crossing point |
| `iwa-2m` | Work not affecting the line: stay at least 2 m from the nearest rail |
| `iwa-patrol` | Patrolling alone: look up every 5 s, reach safety 10 s early, no crossing other open lines |
| `iwa-dark` | No patrolling alone in darkness, poor visibility or a tunnel |
| `iwa-rigid` | Rigid/tensioned barrier or permanent fence at 1.25 m: work on the safe side |
| `iwa-tape` | Tape/netting at 1.25 m only up to 40 mph; at 2 m any speed |
| `iwa-09` | Never use a 0.9 m barrier, even with ATWS |
| `iwa-atws` | Equipment warning: competent, warns of all trains, safety 10 s before; test first |
| `iwa-calc` | Add 5 s for working alone, 10 s minimum in safety; total 45 s or less |
| `iwa-ctlwhen` | Crossing the Line: only while walking, never during work, patrols or inspections |
| `iwa-ctlcall` | Tell the signaller the crossing point, name and employer, and time needed; stay on the phone |
| `iwa-carry` | Crossing the Line: don't carry anything that affects walking safely |
| `iwa-affect` | Line-affecting work for an IWA: block the line first |
| `iwa-dets` | Place detonators only once the PICOP confirms the signal at danger; WSMBs only with ES permission |

## PC / Blockages · Handbook 8 (Issue 10) (21 rules)

| Scene | Rule |
|---|---|
| `pc-scope` | HB8 is for blockages with no trains or on-track plant involved |
| `pc-agree` | What to agree with the signaller when arranging a blockage |
| `pc-200` | Work normally no closer than 200 m to the protecting signal; closer means telling the signaller |
| `pc-form` | Record the blockage on an NR3180 and read it back |
| `pc-wait` | Wait for the signaller to confirm the protecting signal is at danger and will stay so |
| `pc-addprot` | Additional protection wherever possible; always if work affects line safety |
| `pc-methods` | Additional protection methods under HB8 |
| `pc-dets` | Three detonators, same rail, 20 m apart, PLB at the first |
| `pc-both` | Detonator protection in both directions on single or bi-directional lines |
| `pc-tcod` | T-COD only where authorised, signalling working normally, track circuit unaffected; ask first, report after |
| `pc-granted` | The blockage is granted when the signaller gives an authority number and you record it |
| `pc-flag` | Red flag or light in the four-foot, visible to approaching drivers, when work affects trains or a group is working |
| `pc-handover` | Explain the blockage, hand over the NR3180, new COSS signs |
| `pc-giveup` | Before giving up: remove flag, T-COD and detonators; tell the signaller name and authority number |
| `pc-overrun` | Can't give it up on time: tell the signaller the reason and expected time straight away |
| `pc-resume` | Resuming a suspended block means repeating the steps and a new authority number |
| `pc-appoint` | Appoint a PC when two or more COSSs or IWAs need a block at the same place and time |
| `pc-arm` | PC armlet: PC in green on white |
| `pc-sign` | Each COSS or IWA sharing signs the NR3180; the PC briefs each |
| `pc-release` | The PC keeps the blockage until every COSS/IWA confirms they're finished |
| `pc-rp` | The route-proving train doesn't move until you confirm everything is clear |

## AC lines · Handbook 16 (Issue 7, June 2026) (26 rules)

| Scene | Rule |
|---|---|
| `ac-cert` | Your PTS must be valid for overhead-electrified lines |
| `ac-doubt` | If in doubt, treat OLE as live and dangerous |
| `ac-danger` | OLE, pantographs and roof equipment can kill if touched or approached |
| `ac-off` | Even after switch-off, treat it as dangerous until a permit or local isolation document applies |
| `ac-275` | Keep yourself and anything you hold at least 2.75 m from live OLE |
| `ac-long` | Carry long items horizontally and get help |
| `ac-cant` | Never above cant rail level; never climb onto the roof or above cab floor level |
| `ac-object` | Don't approach or remove anything on or near live OLE; report it |
| `ac-broken` | Broken or displaced wires are live and dangerous |
| `ac-report` | Defects to report to the ECO straight away |
| `ac-sig` | If it affects trains, or you don't normally talk to the ECO, tell the signaller |
| `ac-redbond` | Don't touch broken rails, a red-marked bond or anything connected |
| `ac-plate` | Give the ECO your details, line, location and the nearest structure number |
| `ac-msgid` | Quote the ECO's message ID every time you speak to them |
| `ac-emerg` | Emergency: call the ECO immediately, opening with "This is an emergency call" |
| `ac-emerg2` | Emergency: give the reason, whether anyone is in danger from live OLE, and whether emergency services are waiting |
| `ac-trains` | An emergency switch-off, isolation or permit doesn't mean trains have stopped |
| `ac-approach` | After an emergency switch-off: safe to approach, not to touch |
| `ac-rescue` | Isolate and earth before rescuing anyone within 2.75 m, except in narrow cases with 600 mm clearances |
| `ac-ttb` | The COSS must see test before touch and sign the permit before work starts |
| `ac-brief` | Everyone understands the permit conditions before work |
| `ac-move` | Work moves to another part of the OLE: repeat test before touch |
| `ac-lost` | Lost permit: tell the NP straight away; a duplicate is issued |
| `ac-end` | Before returning the permit: everyone and everything 2.75 m clear, treat OLE as live |
| `ac-relief` | Permit handover: both sign, brief the new COSS, NP informed |
| `ac-newole` | New or extended OLE: rules apply once it's declared live in an energisation notice |

## DC lines · Handbook 17 (Issue 6, June 2026) (24 rules)

| Scene | Rule |
|---|---|
| `dc-cert` | Your PTS must be valid for DC electrified lines |
| `dc-doubt` | If unsure, treat the conductor rail as live |
| `dc-live` | CRE and shoe gear are live unless a permit or ECO confirmation says otherwise |
| `dc-step` | Never touch or step on CRE, shoe gear or guard boarding |
| `dc-between` | Never step between the conductor rail and the running rail beside it |
| `dc-tools` | Don't let clothing, tools or anything carried touch CRE; never drag or drop onto it |
| `dc-shoes` | Never touch collector shoes, touching the rail or not |
| `dc-flood` | Don't step in flood water that may touch CRE; report above sleeper level to the ECO |
| `dc-jet` | Never direct a jet of water onto CRE |
| `dc-runrail` | Don't touch broken running rails or bridge the gap |
| `dc-cables` | Treat lineside cables as live; leave them and their covers alone |
| `dc-report` | Damage affecting trains: signaller first; then report defects to the ECO |
| `dc-15` | Keep at least 1.5 m from live CRE without a method statement and risk assessment |
| `dc-shield` | Fit a conductor rail shield before working points beside live, unguarded CRE |
| `dc-clip` | Clip: furthest rail first on, nearest rail first off; detonators on the far rail |
| `dc-vehicle` | Work on the side furthest from live CRE, or fit a shield |
| `dc-emerg` | Emergency: "This is an emergency call"; say why, who's in danger, short-circuiting bars, services |
| `dc-scb` | Use an SCB only if you can't reach the ECO, someone's in danger, and you're competent; never with guard board or yellow shroud |
| `dc-rescue` | Switch off before rescuing anyone within 300 mm, except in narrow emergency conditions |
| `dc-crp` | No isolation-dependent work until the CRP is received; brief the limits |
| `dc-crplost` | Lost CRP: tell the authorised person; a duplicate is issued |
| `dc-approach` | Confirmed off in an emergency: safe to approach but not to touch |
| `dc-short` | Treat CRE as live while finding a short circuit; don't remove the object until the ECO says |
| `dc-tunnel` | Don't enter a tunnel looking for a short until a line blockage protects you and the ECO knows |

| Scene | Rule |
|---|---|

| `hs-see` | Make sure the intended person can see the signal and nobody else acts on it |
| `hs-ground` | Hold the flag or lamp steady; never put it on the ground |
| `hs-mislead` | Near a signal at danger, never give a handsignal that could mislead a driver past it |
| `hs-age` | Don't use detonators over 5 years old, or rusty or damaged ones |
| `hs-detpos` | A detonator placed at a signal goes on the rail at that signal |
| `hs-sprs` | SPRS: check proceed aspect, signaller's permission, operate, check danger, tell signaller |
| `hs-when` | Handsignalling only for single line working, appointed by the pilot |
| `hs-other` | Don't act as handsignaller for any other activity |
| `hs-stay` | Don't leave until relieved or the pilot says you're no longer needed |
| `hs-pass` | Signaller's agent: a train passes the end of degraded working sign without permission, emergency call |
| `hs-wrong` | Intermediate handsignaller: one detonator on the SLW line, hand danger until the train stops |
| `hs-yellow` | Remove the detonator, repeat the signaller's instructions, show yellow |
| `hs-after` | Replace the detonator and show danger, unless the next train is right-direction |
| `hs-right` | No handsignals for right-direction trains; detonator off for it, back after |
| `hs-lc` | Don't be stationed or use a phone at limited clearance unless arrangements are made |
| `hs-tent` | Tent: approved, secured, closed end to trains, 2 m from open line (1.25 m at 20 mph or less) |
